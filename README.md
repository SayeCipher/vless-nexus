## ✨ Overview

**VLESS Nexus Pro** turns your VLESS links into the new format in one click. Paste links, load a subscription, or drop in a file, and get clean, ready-to-use configs back.

Everything runs **100% in your browser** 🔒. There is no server and nothing is uploaded.

## 🤝 Nahan Panel Compatibility

Configs generated by Nexus Pro are **fully compatible with [Nahan](https://github.com/itsyebekhe/nahan) (پنل نهان)**, the serverless VLESS / Trojan gateway for Cloudflare Workers by [@itsyebekhe](https://github.com/itsyebekhe) ✅
Import the output links straight into the panel with no manual editing.

| 🔒 | **Private** | All processing stays on your device |

## 🛠️ What Gets Converted

For every `vless://` link, the converter:

1. 🎭 Replaces `fp=chrome` with `fp=unsafe`
2. 🧩 Adds the TLS fragment settings (`fm=...`) if they are missing
3. 🛡️ Adds `insecure=0` and `allowInsecure=0` if they are missing

Lines that do not start with `vless://` are skipped and counted separately.

## 📖 How to Use

1. 🌐 Open the page
2. 🗂️ Pick an input tab: **Paste**, **Subscription** or **File**
3. ▶️ Press **Convert configs**
4. 📋 Use **Copy all** or **Download .txt**
5. 📲 Import the result into your client or panel

## 💻 Run Locally

No build step, no dependencies 🎉
Download [`index.html`](https://github.com/SayeCipher/vless-nexus/blob/main/index.html) and open it in any modern browser.

## ☁️ Deploy on GitHub Pages

1. 📄 Put the file in the repository root and name it `index.html`
2. ⚙️ Go to **Settings → Pages**
3. 🌿 Under **Source**, choose **Deploy from a branch**, then select `main` and `/ (root)`
4. 💾 Save, and your site goes live in a minute or two

## ⚠️ Good to Know

- 🌍 Subscription loading happens directly from your browser, so the subscription server must allow cross-origin requests (CORS). If it does not, paste the content into the input box instead.
- 🔐 Keep your subscription links private. Anyone with the link can use your configs.
