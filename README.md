# VLESS Nexus Pro

Smart VLESS converter & subscription manager, in a single HTML file.
Crafted by [@SayeCipher](https://github.com/SayeCipher).

Paste your VLESS links, load a subscription, or drop in a file, and get back configs in the new format with one click. Everything runs in your browser. There is no backend and nothing is uploaded anywhere.

**Live demo:** `https://USERNAME.github.io/REPO-NAME/`

## Compatibility with Nahan panel

Configs generated by Nexus Pro are fully compatible with **Nahan panel**. Output links can be imported into the panel and used as they are, with no manual editing.

## Features

- **Three input methods:** paste text, load a subscription URL, or upload / drag and drop a file
- **Base64 aware:** subscription content is decoded automatically; plain `vless://` lists work too
- **One-click conversion** of every `vless://` link, with a live counter for lines read, converted and skipped
- **Copy all** or **download** the result as `converted-vless.txt`
- **Light and dark themes**, following your system setting
- **Responsive** layout for desktop and mobile
- **Privacy first:** all processing is local to your browser

## What the converter changes

For each `vless://` link, the converter:

1. Replaces `fp=chrome` with `fp=unsafe`
2. Adds the TLS fragment settings (`fm=...`) if the link does not already have them
3. Adds `insecure=0` and `allowInsecure=0` if they are missing

Lines that do not start with `vless://` are skipped and counted separately.

## Usage

1. Open the page.
2. Choose an input tab: **Paste**, **Subscription** or **File**.
3. Press **Convert configs**.
4. Use **Copy all** or **Download .txt**, then import the result into your client or panel.

## Run locally

No build step and no dependencies. Download `index.html` and open it in any modern browser.

## Deploy on GitHub Pages

1. Put the file in the repository root and name it `index.html`.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save, and the site goes live after a minute or two.

## Notes

- Loading a subscription from a URL happens directly from your browser, so the subscription server must allow cross-origin requests (CORS). If it does not, paste the content into the input box instead.
- Always keep your subscription links private. Anyone who has the link can use the configs.
